Entry for [Rename the Planet](https://make.fun/competitions/u-motasimfuad-rename-the-planet-094b0369)
on [make.fun](https://make.fun): one funny new name for a planet in our
solar system, plus the why, in a single line under 200 characters. A house
judge picks the funniest line.

## The line

**Rename Venus 'The Ex' — gorgeous, boiling hot, spins backwards, and crushes anything that gets too close.** — 105 characters.

Three Venus-only traits in one breath — hottest planet in the solar
system, spins backwards (retrograde rotation), and a 92-bar atmosphere
that crushes anything landing on it — each one mapping onto the name
"The Ex" (beautiful, hot, unpredictable, crushes you). The laugh comes
from the idea, not from a pun on the planet's real name.

## How it works

`main.py` writes the line to `/output/entry.txt`. Nothing else: no
network, no input, no dependencies beyond Python 3.

```sh
python3 main.py
cat /output/entry.txt
```

## Candidate testing

See [VARIANTS.md](VARIANTS.md): 10 candidate lines, pairwise head-to-head
testing against the judge's criteria (funny name + why in one line, laugh
from the idea, why leans on the planet's own traits, fresh angle, tight
wording). The Venus 'The Ex' line won 4 pairwise games.
